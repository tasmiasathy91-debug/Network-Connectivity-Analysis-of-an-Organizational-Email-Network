# Project Title:
Network Connectivity Analysis Using Email Communication Data

# Dataset: 
assets/email_network.txt

# Project Overview:

This project examines network connectivity using an email communication dataset stored in the file assets/email_network.txt. The primary objective is to represent email communication as a graph and analyze the relationships between individuals through nodes and edges. NetworkX, a Python library for network analysis, provides tools for loading, constructing, visualizing, and analyzing graph structures.

The project focuses on identifying connected components, examining the relationships among network participants, and understanding how information may travel through a communication network. The analysis demonstrates how graph theory can support the study of communication patterns, organizational relationships, and network structure. The findings can provide insights into the connectivity of individuals and the overall organization of an email communication network.

# Keywords: 
Network connectivity, graph theory, NetworkX, email communication, connected components, Python, data analysis.

# Project Objectives

The main objectives are:
1. To load and examine the email network dataset.
2. To represent email communication as a graph.
3. To identify the number of nodes and edges in the network.
4. To determine whether the network is connected.
5. To identify connected components and isolated nodes when present.
6. To visualize the network structure for easier interpretation.
7. To interpret the results in the context of communication and information flow.
